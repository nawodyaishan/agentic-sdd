# Agentic SDD Teach

Read the [shared policy](../agentic-sdd-router/references/workflow-policy.md) once
per unchanged context. Teaching is a separate requested activity, not feature
approval, batch execution or permission to create learning files.

## Lightweight default

Reuse the user's stated learning question and relevant known context. Give a
short explanation and one useful example or practice question; invite feedback
and adjust to demonstrated understanding. Investigate version-sensitive facts
through permitted sources, attributing uncertainty instead of guessing.
Do not force an interview, create lesson files/assets, launch a browser, contact
communities or advance the feature. Return to execution only within actual
authority, not because the lesson ended.

## Persistent learning — only when explicitly requested

Read [learning workspace guidance](references/learning-workspace.md). Establish
the selected workspace, learning goal, allowed artifacts and effects, reusing
known answers. Preserve existing files and choose non-colliding paths. A feature
checkout is not automatically converted into a course.

Tie each short lesson/practice loop to the agreed goal and existing knowledge.
Use trusted sources and small reusable references; create supporting directories
and assets lazily. Record demonstrated understanding or attributed prior
knowledge, not merely a topic covered. Confirm a changed mission before updating
it. Browser launch, external sharing, community interaction and additional model
research require their applicable permissions; no automatic delegation.

Finish with what was taught, evidence/remaining uncertainty and the user's next
learning choice. Teaching records never become a second feature-state ledger.
