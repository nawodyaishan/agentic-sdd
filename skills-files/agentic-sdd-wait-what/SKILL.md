# Agentic SDD Wait What

Read the [shared policy](../agentic-sdd-router/references/workflow-policy.md) once
per unchanged context. This invocation is **explanation only**; change no files,
verdicts, approvals, task state or batch selection, and run no tests or live actions.

Re-pitch briefly:

- What the user is trying to achieve and which stage we are actually in.
- What exists, what remains and why the current recommendation follows.
- Which statements are observed, proposed or still uncertain.
- The next consequential decision or already permitted action, if any.

Use familiar project/glossary terms where available. Explain jargon rather than
requiring a glossary file or claiming formal simplified-English conformance.
Do not re-open settled questions or turn confusion into consent to implement.
If the explanation exposes a necessary change, describe it and seek only the
required scoped decision; preserve the invoking workflow's existing authority.
