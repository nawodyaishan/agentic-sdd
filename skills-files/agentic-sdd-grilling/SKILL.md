# Agentic SDD Grilling

Read the [shared policy](../agentic-sdd-router/references/workflow-policy.md) once
per unchanged context and the [human-input contract](../agentic-sdd-router/references/human-input.md)
when conducting a question round. This is a clarification procedure, not a
domain specialist or permission to start a new workflow.

1. Identify the decision and the work it blocks. Reuse settled answers, relevant
   source requirements and actual authority. A clear request proceeds without
   an interview; an explicit challenge stays within the plan being challenged.
2. Investigate discoverable repository/environment/documentary facts through
   permitted tools in the main agent. Distinguish evidence from assumptions.
   A fact needing access you lack stays unknown; do not delegate automatically.
3. Map consequential decisions and their dependencies. Ask only the ready
   frontier: no more than three independent questions per round, each with
   rationale, a recommendation and credible alternatives/costs. Neutral choices
   must not make every “yes” accept an unstated bundle of assumptions.
4. Reconcile the actual answers. Separate preferences, observed facts, approval
   and permission. Resolve contradictions or name the responsible decision owner.
   Record authorized requirement/design inputs in their existing source; in
   review-only mode return proposed updates without writing them.
5. Stop when material choices are resolved or explicitly blocked. Report what
   was settled, what remains unknown and the invoking stage's next permitted
   action. Do not exhaust hypothetical branches or re-ask unchanged decisions.

Shared understanding closes clarification only. A changed consequential contract
needs the existing scoped decision; unaffected approval survives. Continue only
work already authorized, not a new batch inferred from the answers.
