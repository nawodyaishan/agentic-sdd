## What this session did

- Researched the migration with Exa and Context7:
  - GoReleaser `v2.10` deprecated `brews`; `v2.16` calls it fully deprecated. `homebrew_casks` is the supported path for prebuilt binaries.
  - GoReleaser `v2.14.0` accepts only string names in `homebrew_casks.binaries`; a `{name, target}` map is rejected by `goreleaser check`. Homebrew can rename a `binary` with `target:`, but GoReleaser does not expose it at this version.
  - Casks quarantine downloads. Unsigned binaries can be blocked by Gatekeeper, so the reviewed cask adds a post-install `xattr -dr com.apple.quarantine` hook for both binaries. Signing/notarization is the alternative.
  - Homebrew measure: formula→cask migration in a third-party tap needs Homebrew `>=5.0.6`, an existing cask, and `tap_migrations.json` plus formula deletion in the **same pushed tap commit**. `brew update` migrates, unlinks the formula, and asks the user to uninstall it.
